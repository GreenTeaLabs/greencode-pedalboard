# Greencode Pedalboard

Releases of Greencode Pedalboard, a pedalboard app for Windows by Green Tea Labs, for any
instrument. The app looks here for new versions and installs them in one click.

The app asks for the licence key from your purchase: https://greentealabs.gumroad.com/l/mvxhm
